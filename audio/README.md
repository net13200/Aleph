# הקלטות

כל מה שהילד שומע מזוהה במפתח קבוע:

| מפתח | מה נשמע |
| --- | --- |
| `letter.ד` | שם האות |
| `syl.ב.a` | צירוף: אות + צליל (`a` קמץ/פתח, `i` חיריק, `o` חולם, `e` סגול/צירה, `u` שורוק/קובוץ) |
| `nq.kamatz` | שם סימן הניקוד |
| `word.דָּג` | מילה |
| `part.זוֹן` | הברה מתוך מילה (כשאינה צירוף פשוט) |
| `sylsoft.ב.a` | צירוף עם ב/כ/פ רפה או שׂ |
| `sentence.הַדָּג בַּמַּיִם` | משפט |
| `p.whereLetter`, `p.letsPlay.f` | משפטי הדמות (`.m`/`.f` לפי לשון הפנייה) |
רשימת כל המפתחות והטקסטים מופיעה באפליקציה: אזור הורים ← בדיקת קול.

כדי להחליף את הקול של המכשיר בהקלטה שעברה בדיקה, שמים את הקובץ בתיקייה הזו ומוסיפים אותו ל־`manifest.json`:

```json
{
  "letter.ד": "letter-dalet.mp3",
  "word.דָּג": "word-dag.mp3"
}
```

מפתח שאין לו קובץ ממשיך להישמע בקול העברי של המכשיר. אחרי הוספת קבצים צריך להעלות את `CACHE` ב־`sw.js` (למשל `aleph-v2`) כדי שהמכשירים יורידו אותם.
