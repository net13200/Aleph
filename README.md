# אלף

אפליקציה שמלמדת ילד בכיתה א׳ לקרוא עברית מנוקדת — אותיות, סימני ניקוד ומילים — בקצב שלו, ומשלימה את מה שנלמד בכיתה.
נפתחת עם אנימציית הפתיחה של SugiGames.

אתר סטטי (PWA), בלי שלב בנייה. עובד בלי אינטרנט אחרי הטעינה הראשונה, וכל המידע נשמר על המכשיר בלבד.

## הרצה

```sh
npx http-server -c-1 .
```

ואז לפתוח את הכתובת בטלפון ("הוספה למסך הבית" באייפון / "התקנת אפליקציה" בכרום באנדרואיד).
צריך שרת (לא `file://`) כדי שמצב לא־מקוון יעבוד.

## מה יש באפליקציה

- **פרופיל** שההורה יוצר: שם, לשון פנייה (בן/בת), כיתה, אילו אותיות וסימני ניקוד נלמדו, מהירות קול.
- **אותיות**: 22 אותיות ו־5 סופיות. **כל סימני הניקוד** לפי סדר התוכנית: קמץ ופתח, חיריק, חולם, סגול וצירה, שורוק וקובוץ.
- **תרגילי אותיות**: שמע ובחר, צליל פותח, צליל סוגר, עקיבה (כיוון וסדר משיכות, עם הדגמה וסליחה על חוסר דיוק קטן).
- **תרגילי צירופים**: שמע ובחר צירוף, וגלגל צירופים — שורה שבה משתנה רק האות או רק הניקוד, והדמות קוראת אותה לפני השאלה. כשסימן ניקוד מופיע לראשונה יש היכרות קצרה.
- **תרגילי מילים**: מילה ותמונה (קריאה עם הבנה, בלי שהמילה מוקראת), מה חסר?, הרכב מילה מצירופים. מילה מוצגת רק כשכל האותיות וסימני הניקוד שלה נלמדו; חלוקת המילים להברות נעשית אוטומטית מהכתיב המנוקד.
- **כללי קריאה** (ההורה מסמן כשנלמדו בכיתה):
  - ה׳ בסוף מילה (אהו״י כתנועה) — "איפה כתוב" בין זוגות כמו חוֹל / חוֹלָה.
  - אותיות שנשמעות אותו דבר — "איזו אות נשמעת כמו ת?" (ט–ת, ק–כּ, ח–כ, ס–שׂ, ו–ב, א–ע).
  - אותיות שהניקוד משנה — שמיעה והבחנה בין בּ/ב, כּ/כ, פּ/פ, שׁ/שׂ.
  - אותיות סופיות — בחירת הצורה הנכונה בסוף מילה (לֶחֶם, לא לֶחֶמ).
  - קריאת משפטים קצרים — קוראים משפט ובוחרים את התמונה המתאימה מבין שלוש.
  - מילים עם ה׳ שקטה בסוף או עם ב/כ/פ בלי דגש מופיעות רק אחרי שהכלל המתאים סומן.
- **אותיות דומות**: מופיע רק אצל ילד שמתבלבל שוב ושוב בין זוג (למשל ד/ר), ומסתיים בהשוואה של שתי האותיות.
- **משוב על טעות**: בטעות הראשונה — "זו האות ר׳, אנחנו מחפשים את ד׳" ונסיון נוסף; בשנייה — מראים את התשובה והפריט חוזר מאוחר יותר באותו ששן.
- **התקדמות**: פריט נחשב נלמד אחרי 3 תשובות נכונות ברצף בשני ששנים שונים. צירופים נפתחים אחרי שהאות נלמדה, ומילים אחרי שכל האותיות שבהן נלמדו.
- **ששן קצר**: עד 10 תרגילים או 8 דקות, מסך סיום ומדבקה לכל אות שנלמדה.
- **אזור הורים** (לחיצה ארוכה על המנעול + תרגיל כפל): מפת אותיות, מצב כל סימן ניקוד, מילים שנקראו, בלבולים נפוצים, דקות תרגול השבוע, גיבוי ושחזור, בדיקת קול.

## קול

כל הנחיה נשמעת בקול. סדר העדיפויות: הקלטה בקול של ההורה (נשמרת במכשיר) ← הקלטה סינתטית שעברה בדיקה אוטומטית ← הקלטה שההורה האזין לה ואישר ← הקול העברי של המכשיר.

ההקלטות נוצרות בכלי `tools/voice/` לפי התהליך שב־spec (ניקוד ← Phonikud ← קול סינתטי ← בדיקת אורך וזיהוי דיבור). משפטים, הנחיות ורוב המילים עוברים בדיקה אוטומטית; אותיות וצירופים קצרים מדי לזיהוי דיבור ולכן ממתינים להאזנה באזור ההורים ← בדיקת קול. פרטים ב־[`tools/voice/README.md`](tools/voice/README.md).

## עוד לא באפליקציה

זיהוי דיבור ("קרא בקול"), שווא וחטפים, תוכן כיתה ב׳, ופרופילים נוספים.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `js/splash.js` | אנימציית הפתיחה של SugiGames |
| `js/data.js` | אותיות, ניקוד, מילים, מסלולי עקיבה, משפטים מדוברים |
| `js/store.js` | שמירה מקומית, מעקב התקדמות ותכנון ששן |
| `js/audio.js` | הקלטות / קול המכשיר, צלילי משוב |
| `js/trace.js` | רכיב העקיבה |
| `js/app.js` | מסכים, תרגילים ואזור ההורים |
| `sw.js` | מצב לא־מקוון |
